# Lab 1D: Optionals and Safe Unwrapping

## Objective
Understand Swift optionals and safely handle values that may be missing.

## Concepts Covered

1. **Optional Return:** Created a function that returns student marks as an optional integer.
2. **if let:** Safely unwraps an optional value when available.
3. **guard let:** Handles missing values and exits the function safely.
4. **Optional Chaining:** Accesses an optional student's email safely.
5. **Nil-Coalescing Operator:** Provides a default value when marks are unavailable.
6. **Empty Input Handling:** Checks and handles an empty text field.
7. **Safe Unwrapping:** Retrieves optional values without force unwrapping.
