
# Lab 8C: State Management

## Objective
Choose suitable state ownership and propagate changes through multiple SwiftUI Views.

## Requirements Covered

1. Used @State for local search text.
2. Used CourseStore as a shared ObservableObject.
3. Used @Binding to update favourite status from child Views.
4. Added and removed favourite courses with synchronized list and detail Views.
5. Explained SwiftUI state wrappers and local vs shared state.

## Technologies
- Swift
- SwiftUI
- @State
- @StateObject
- @ObservedObject
- @Binding
- @Published
- ObservableObject
