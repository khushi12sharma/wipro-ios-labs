# Lab 2A: Functions and Higher-Order Functions

## Objective
Practice reusable functions and Swift higher-order functions such as `map`, `filter`, `reduce`, and `sorted`.

## Requirements Covered

1. **Reusable Functions:** Calculate mean, find maximum, validate email-like input, and format display names.
2. **Transaction Processing:** Use `filter`, `map`, and `reduce` to process expenses and calculate total spending.
3. **Student Sorting:** Sort students by marks in descending order and names alphabetically when marks are equal.
4. **Approach Comparison:** Compare loop-based and higher-order function solutions.
5. **Clear Function Design:** Use descriptive parameter labels and explicit return types.

## Optional Extension
Created a category-wise spending report using filtering, mapping, and reducing.
