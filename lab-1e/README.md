# Lab 1E: Classes, Structs, ARC, and Memory

## Objective
Compare Swift value types and reference types and understand ARC memory management.

## Requirements Covered

1. **Struct and Class:** Created a `Course` struct and a `CourseManager` class.
2. **Value vs Reference Behaviour:** Modified copies to observe the difference between struct and class behaviour.
3. **Weak References:** Created related `Teacher` and `Classroom` classes using a weak reference.
4. **Strong Reference Cycle:** Demonstrated a closure capturing `self` strongly and prevented the cycle using `nil` and `[weak self]`.
5. **ARC:** Used `deinit` logging to observe when class instances are released.

## Files

- `ClassesStructsARC.swift` — Complete Swift source code.
- `LabReport.md` — Observations and explanation of memory management.
- `README.md` — Lab overview and requirements.

## Execution

The Swift program was executed successfully using JDoodle.

## Conclusion

The lab demonstrates value semantics, reference semantics, weak references, strong reference cycle prevention, and ARC memory management.
