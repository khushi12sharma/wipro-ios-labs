# Lab 1A – Swift Basics, Variables, Types and Operators

## Objective
To understand Swift variables, constants, data types, operators, conditional statements and input validation through a Student Grade Calculator.

## Features
- Stores student name and roll number.
- Accepts marks in five subjects.
- Calculates total, average and percentage.
- Checks pass/fail status.
- Calculates grades using switch statements.
- Demonstrates arithmetic, comparison and logical operators.
- Demonstrates compound assignment and nil-coalescing operators.
- Validates marks and attendance boundaries.

## Concepts Used
- Constants (`let`) and Variables (`var`)
- Data Types: String, Int, Double and Bool
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Compound Assignment Operators
- Nil-Coalescing Operator
- if/else and switch
- Functions and Arrays
- Input Validation

## Pass Criteria
- Minimum 35 marks in every subject.
- Minimum 75% attendance.

## Grade Criteria
| Average | Grade |
|---|---|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 50–59 | E |
| Below 50 | F |

## Files
- `main.swift` – Main Swift program.
- `test-cases.md` – Eight test scenarios.

## How to Run
1. Open JDoodle or a Swift-supported environment.
2. Paste the contents of `main.swift`.
3. Execute the program.
4. Enter student details, marks and attendance.

## Testing
Eight test cases are documented in `test-cases.md`, covering normal inputs, failing marks, maximum marks and invalid attendance.

## Conclusion
This lab demonstrates fundamental Swift programming concepts through a practical Student Grade Calculator.
