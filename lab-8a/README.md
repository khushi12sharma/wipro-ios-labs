
# Lab 8A: SwiftUI App Structure and Views

## Objective
Build a Course Explorer application using SwiftUI.

## Features
- Course Explorer home screen
- Course cards with category labels
- Category filtering
- Course detail screen
- Reusable custom views
- Empty state for unavailable courses
- Navigation between screens

## Technologies
- Swift
- SwiftUI
- NavigationStack
- VStack, HStack and ZStack
- ScrollView and List

## Project Files

| File | Description |
|---|---|
| README.md | Project overview |
| Course.swift | Course model and sample data |
| CourseCardView.swift | Reusable course card |
| CourseDetailView.swift | Course detail screen |
| EmptyStateView.swift | Empty state screen |
| CourseExplorerView.swift | Main Course Explorer screen |
| CourseExplorerApp.swift | App entry point |
| ViewStructure.md | View hierarchy documentation |
| TestCases.md | Test cases and requirement mapping |
