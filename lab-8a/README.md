
# Lab 8A: SwiftUI App Structure and Views

## Objective
Build a Course Explorer application using SwiftUI.

## Requirements
1. Display an app title and course cards.
2. Show course category labels.
3. Provide a course detail screen.
4. Use VStack, HStack, ZStack, ScrollView and List.
5. Create reusable custom views.
6. Include an empty state when no courses are available.
7. Keep SwiftUI view bodies readable and organized.

## Technologies
- Swift
- SwiftUI
- Custom Views
- NavigationStack
- Preview support
