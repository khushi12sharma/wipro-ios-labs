# Lab 2C – Protocols, Extensions, and Generics

## Objective
To practice abstraction, code reusability, and type safety using Swift protocols, extensions, and generics.

## Concepts Covered

### 1. Protocols
- Created a `Displayable` protocol.
- Implemented it in `Student` and `Course`.

### 2. Extensions
- Extended String with a word-count property.
- Added a method to reverse a string.

### 3. Generics
- Created a reusable generic Stack structure.
- Implemented push, pop, peek, and isEmpty.
- Tested the stack with Int and String.

### 4. Protocol Constraints
- Created a generic function restricted to Displayable types.
- Demonstrated valid and invalid usage.

### 5. Stack Protocol
- Created a custom StackProtocol.
- Made the generic Stack conform to it.
