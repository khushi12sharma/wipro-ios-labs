# Lab 1C: Collections and Enums

## Objective
Understand how to store and transform related data using Swift Array, Set, Dictionary, and enum.

## Operations Performed

### 1. Array
- Added a new course.
- Removed a course.
- Sorted course names.
- Filtered courses containing a specific character.
- Searched for a course.

### 2. Set
- Removed duplicate student IDs.
- Displayed unique student IDs.
- Calculated the unique student count.

### 3. Dictionary
- Stored student IDs and marks.
- Found the student with the highest marks.
- Identified students scoring below 60.

### 4. Enum and Switch
- Created a TaskPriority enum.
- Used switch to display user-friendly priority labels.

### 5. Associated Values
- Created an APIResult enum with success data and failure message cases.
- Used switch to handle both results.
