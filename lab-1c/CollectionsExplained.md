# When to Use Array, Set, and Dictionary in Swift

## 1. Array
An Array is used when we need to store an ordered collection of values.

- Maintains the order of elements.
- Allows duplicate values.
- Supports adding, removing, sorting, and filtering.

**Example:** Storing course names such as Java, Python, and Swift.

## 2. Set
A Set is used when we need to store unique values.

- Does not store duplicate elements.
- Does not guarantee insertion order.
- Provides efficient membership checking.

**Example:** Storing unique student IDs without duplicates.

## 3. Dictionary
A Dictionary is used when we need to store data as key-value pairs.

- Each key is unique.
- Values are accessed using their keys.
- Useful for mapping related information.

**Example:** Mapping student IDs to their marks.

## Comparison

| Collection | Best Use | Example |
|---|---|---|
| Array | Ordered data | Course names |
| Set | Unique data | Student IDs |
| Dictionary | Key-value data | Student marks |

## Conclusion
Array, Set, and Dictionary are useful Swift collections. We choose between them based on whether we need ordered elements, unique values, or key-value mapping.
