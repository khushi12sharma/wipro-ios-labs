
# Lab 4A – MVC and MVVM

## Objective
To understand how to separate UI, application state and business logic using MVC and MVVM architectures.

## Application
Task List App

## Features
1. Add new tasks.
2. Mark tasks as completed.
3. Delete tasks.
4. Filter tasks into All, Pending and Completed.

## Architectures
- MVC: Model, View and Controller.
- MVVM: Model, View and ViewModel.

## Requirements
- R1: Build a task-list application.
- R2: Implement MVC architecture.
- R3: Implement MVVM architecture.
- R4: Separate filtering and validation logic.
- R5: Compare both architectures.

## Testing
Business logic will be tested independently using Swift test cases.

## Conclusion
This lab demonstrates separation of responsibilities and testable application architecture.
