
# Lab 8B: Navigation and Basic Template

## Objective
Build a basic SwiftUI application demonstrating app structure and navigation.

## Requirements Covered
1. Inspect the @main App entry point and initial WindowGroup.
2. Use NavigationStack and NavigationLink.
3. Pass the selected Product model to the detail view.
4. Add a Featured toolbar action and support back navigation.
5. Explain the difference between an App entry point and a View.

## Technologies
- Swift
- SwiftUI
- NavigationStack
- NavigationLink
- NavigationPath
- Toolbar
- WindowGroup
