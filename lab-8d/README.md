# Lab 8D: SwiftUI Layout and Form Interaction

## Objective
Build an event registration form using SwiftUI components and demonstrate form validation, layout, and user interaction.

## Features
- Text fields for full name and email address.
- Picker to select an event.
- Toggle for receiving event updates.
- Terms and conditions acceptance.
- Submit button with disabled state for incomplete required fields.
- Validation feedback and success confirmation.
- Form sections with padding and spacing.

## SwiftUI Concepts
- `Form` and `Section`
- `TextField`, `Picker`, and `Toggle`
- `@State` for managing form data
- `Button` and conditional validation
- `NavigationStack`
- Disabled button states

## Files
- `EventRegistrationApp.swift` — App entry point.
- `EventRegistrationView.swift` — Event registration form and validation.
- `README.md` — Project documentation.
- `TestCases.md` — Test scenarios and execution status.
