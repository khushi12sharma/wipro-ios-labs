# Lab 6: Build a Network-Driven Directory

## Objective
Fetch JSON data from a public API, decode it into Swift models, and display user information.

## API Endpoint
https://jsonplaceholder.typicode.com/users

## Technologies
- Swift
- Codable
- URLSession
- async/await
- JSONDecoder

## Features
- Fetch users from API
- Decode JSON response
- Display user list and details
- Handle loading, errors and retry
